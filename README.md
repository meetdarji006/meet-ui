## ✨ Features

- **🚀 Modern Framework**: Built with **Next.js 15+** (App Router) and **TypeScript**.
- **🎨 Stunning Animations**: Powered by **Framer Motion** and **React Three Fiber** (Three.js).
- **⚡ Tailwind CSS v4**: Leveraging the latest experimental features for high-performance styling.
- **🛠️ Fully Customizable**: CSS Variables for theming and easy-to-edit components.
- **📚 MDX Documentation**: Seamlessly integrated documentation with MDX support.
- **🏗️ Component Registry**: A robust system for adding and showcasing new components.

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm / yarn / pnpm

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/meetdarji006/meet-ui.git
   cd meet-ui
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open [http://localhost:3000](http://localhost:3000)** in your browser to see the playground.

## 📂 Project Structure

- `src/app`: App Router pages, layouts, and global styles.
- `src/components/ui`: The core component library.
- `src/lib/components-data`: Registry and code strings for the playground.
- `docs`: Detailed guides, including [adding new components](docs/ADDING_COMPONENTS.md).
